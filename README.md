# PurelyBeingHuman

A website for PurelyBeingHuman

## To-Do List Application

A modern, responsive to-do list application with local storage functionality. Built with vanilla HTML, CSS, and JavaScript.

### Features

✨ **Core Functionality**
- Add, complete, and delete tasks
- Local storage persistence (tasks saved automatically)
- Filter tasks: All, Active, or Completed
- Real-time statistics (Total, Completed, Remaining)
- Clear all completed tasks or entire list

🎨 **User Interface**
- Modern gradient design with smooth animations
- Responsive layout (works on desktop, tablet, mobile)
- Intuitive keyboard support (Enter key to add tasks)
- Visual feedback for completed tasks
- Empty state message when no tasks exist

💾 **Local Storage**
- Automatically saves tasks to browser's local storage
- Persists across browser sessions
- No backend required

### How to Use

1. **Add a Task**: Type in the input field and click "Add Task" or press Enter
2. **Mark Complete**: Click the checkbox next to a task
3. **Delete a Task**: Click the "Delete" button
4. **Filter Tasks**: Use filter buttons to view All, Active, or Completed tasks
5. **Clear Completed**: Remove all completed tasks at once
6. **Clear All**: Delete all tasks (with confirmation)

### Technical Details

**Technologies Used**
- HTML5: Semantic markup
- CSS3: Flexbox layout, gradients, animations
- JavaScript (ES6): Class-based architecture, event handling

**Browser Compatibility**
- Works on all modern browsers (Chrome, Firefox, Safari, Edge)
- Requires JavaScript enabled
- Uses localStorage API (supported by all modern browsers)

### Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Start adding tasks!

### Tips

- Your tasks are saved automatically to local storage
- Clear browser cache/cookies to reset your tasks
- Tasks are sorted by creation time (newest first)
- Use the filter buttons to focus on specific tasks
